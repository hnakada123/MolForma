# 変更履歴

## 1.1.0（2026-11-10）

ローカルで複数の計算を進める機能と、NWChemの物性を可視化する機能を追加しました。

| 計算キュー | [3 実行設定](features/execution.md#計算キュー) → キューに追加 | 分子・条件を登録時に保存し、1件ずつ実行。並べ替え・取消・一時停止、失敗時の停止方針を指定 |
| 失敗原因の案内 | [実行パネル](features/execution.md#失敗原因の案内) | SCF未収束・最適化上限・メモリ・基底・起動失敗・時間切れなどを、ログの根拠とともに表示 |
| 結果から再計算 | [結果ビューア](features/results.md#結果の構造から再計算を準備) → 再計算を準備 | 元のジョブの条件を復元し、表示中の構造を候補として取り込む |

### 利用前に確認すること

- キューはMolFormaを起動している間に逐次実行します。アプリを閉じると実行中の計算は停止し、待機分は入力一式だけが履歴に残ります。順番の復元、自動再開、同時実行、SSH・Slurm／PBSは未対応です。
- 「再計算を準備」は新しいジョブを作るための操作です。NWChemのデータベースやHessianを引き継ぐ`restart`は行いません。
- NMRのJ分裂・常磁性NMR、共鳴ラマン、粉末／高スピンESR、配座平均スペクトルは未対応です。ECDはΔεへ、ORDのβは比旋光度へ換算しません。
- 自由エネルギー比較では、熱補正の温度・出典と虚振動を確認してください。標準状態の欄は記録用で、入力しても濃度・圧力の補正は行いません。配座分布は選択したセット内で、各群の縮重度を1とするモデルです。
- CUBEの単位は生成条件で確認します。色付け用の格子は同じ原子順・座標系で表面全体を覆う必要があり、自動位置合わせは行いません。

### 保存と互換性

既存のMolFormaプロジェクト（`molforma-project`、形式バージョン1）を引き続き読み書きできます。新しい計算条件もプロジェクトへ保存します。配座セット、エネルギー比較、スペクトル表示条件は、それぞれの画面から別のJSONファイルへ明示的に保存してください。スペクトル表示条件は元の結果ファイルと結び付いています。

### 確認した範囲

Linuxで1.1.0のビルド、全16系列のCTest、日英ドキュメントのサイト生成を確認しました。物性の読込と規約はNWChem 7.3.1の小分子の実計算（ラマン・ESR・ECD・ORD・ESP／電場CUBE）で確認しています。小基底の動作確認であり、実験との定量的一致を検証したデータではありません。各OSのインストール手順にある過去の検証記録は、その記載バージョンでの記録です。
