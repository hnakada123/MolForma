# 変更履歴

## 1.1.0（2026-11-10）

ローカルで複数の計算を進める機能、長い計算を止めずに続ける機能、NWChemの物性を可視化する機能に加え、反応経路の計算（NEB・計算の連鎖）、金属錯体の前処理（xTB）、図と動画の書き出し、構造の入手（小分子のCIF・PubChem）と組み立て（多座配位子・η配位・溶媒和殻）、計算条件の拡張（貼り付けた基底・ECP、NMRのJ結合、励起状態の最適化、追加の内部座標、フラグメント初期軌道、2次元スキャン）を追加しました。

### 利用前に確認すること

- キューはMolFormaを起動している間に逐次実行します。ウィンドウを閉じた後も続くのは実行中の1件で、待機分は次の起動時に復元しますが、利用者が再開するまで始まりません。同時実行は未対応です。PCの再起動・ログアウトで計算が終わるかどうかはOSの設定によります。
- リモート実行は、パスワードなしで接続できる（鍵を `ssh-agent` や `~/.ssh/config` で使える）計算機だけが対象です。パスワード・ワンタイムパスワードの入力やホスト鍵の受け入れには対応せず、追加の環境変数は実行先へ渡しません。実際のSSHではLinuxでシェルでの投入を確認しました。Slurm・PBSは試験用のプログラムでだけ確認しています。既定の見出しは1ノード用です。
- 「再計算を準備」は表示中の構造から新しいジョブを作る操作です。NWChemのデータベースやHessianを引き継ぐ場合は、「履歴」の「続きから実行を準備」「この結果から次の計算」を使います。再開は元のジョブのデータベースを新しいジョブフォルダーへ複写して `restart` で始めます。座標スキャン・IRC・BSSE補正と、`permanent_dir`・`scratch_dir` をジョブの外に指定した計算は再開できず、再開する計算では分子と拘束を変更できません。
- NMRのJ分裂は一次の多重線で、等価性は結合の並びだけで判定します。2次効果、常磁性NMR、共鳴ラマン、粉末／高スピンESRは未対応です。ECDはΔεへ、ORDのβは比旋光度へ換算しません。
- 自由エネルギー比較では、熱補正の温度・出典と虚振動を確認してください。熱化学の補正は、NWChemが出力した値の振動部分だけを置き換えます。既定（スケール1・調和振動子・1 atm）ではNWChemの出力値のままです。速度定数は透過係数1のEyring式で、基準の段階からの自由エネルギー差を障壁とみなした値です。配座分布は選択したセット内で、各群の縮重度を1とするモデルです。
- 結合指数は基底関数に依存し、diffuse関数を含む基底では信頼できない値になることがあります。励起状態の軌道の重みは、NWChemが出力した寄与（係数の絶対値が0.05を超えるもの）だけから求めた値です。
- CUBEの単位は生成条件で確認します。色付け用の格子は同じ原子順・座標系で表面全体を覆う必要があり、自動位置合わせは行いません。
- NEBは固定原子・ゴースト、TDDFT・物性計算・後続の一点計算・BSSE補正、CUBE・MOLDENの出力、再開と併用できません。終点は始点と同じ原子を同じ順番で持つ構造に限ります。NWChemのNEBは最大ステップ数で止まっても正常終了し、MolFormaも失敗として扱いません（結果ビューアに未収束と示します）。最高点は遷移状態の目安で、遷移状態探索と振動数での確認が必要です。
- 連鎖で登録した計算は、引継ぎ元が正常に終わった時点で構造を取り込み、入力一式を保存します。引き継ぐのは構造だけで、分子軌道・Hessianは引き継ぎません。
- xtbはMolFormaに同梱しません（LGPL-3.0）。利用者がインストールし、「編集 → 環境設定」の「xTB実行ファイル」で指定します。外部点電荷は含めず、ゴーストとRnより重い元素は扱えません。半経験的手法による前処理で、DFTの最適化の代わりではありません。
- 小分子のCIFは分子を孤立分子として取り出す読込で、周期境界条件の計算（NWChemの `system crystal`）には対応しません。単位格子の原子は6,000個まで、乱れは既定で主成分だけです。水素のないCIFは形式電荷を確かめてから水素を補完してください。
- PubChemで名前に複数の化合物が当たる場合は最初の化合物を開きます。金属を含み3D構造のない化合物（PubChemの錯体の多くはイオンに分けて登録）は開かず、配位ビルダーか結晶構造を使います。
- 多座配位子は部品の形のまま置くため、中心–供与原子の距離が金属に合わないことがあります。供与原子の向きがサイトから25°を超えてずれる組は拒否します。xTBなどで整えてから計算してください。
- 溶媒和殻は形を変えない溶媒分子を接触距離で置く簡易な配置で、水素結合のネットワークや溶媒の密度を再現せず、周期境界の溶媒箱は作りません。
- 貼り付けた基底・ECPの内容（係数・元素への適合）はNWChemが実行時に判定します。基底を貼り付けた元素には、ECPを貼り付けない限りECPを使いません。
- J結合はDFTで、閉殻でもUKS（odft）で計算します。核ごとの応答計算のため時間がかかり、組は2000組までです。
- 励起状態の最適化は閉殻の一重項の励起状態（開殻は非制限の励起状態）を番号で追い、状態の順番が入れ替わると別の状態になります。振動数・遷移状態探索・励起状態のCUBEとは組み合わせられません。
- フラグメント初期軌道は、フラグメントの不対電子の合計が全体と一致するとき（閉殻どうし・高スピン）だけ使え、反強磁性（broken-symmetry）の初期軌道は作れません。スキャン・IRC・NEB・BSSE補正・ゴーストとは併用できません。
- 2次元スキャンは400点までで、各点を独立に計算します（前の点の構造は引き継ぎません）。
- MP4の書き出しにはPATHにある `ffmpeg`（H.264のエンコーダーを含むもの）が必要です。GIFは1枚ごとに最大255色で、透明な背景の輪郭は滑らかになりません。SVGはQt SVGモジュールのあるビルドで選べます。

### 保存と互換性

既存のMolFormaプロジェクト（`molforma-project`、形式バージョン1）を引き続き読み書きできます。新しい計算条件、再開の設定（`document.nwchem.restart`）、ジョブスクリプトの種類（`document.nwchem_execution.job_script`・`job_queue`）、NEBの設定と終点（`document.nwchem.neb_*`、終点は原子の安定IDごとの座標 `neb_end`）もプロジェクトへ保存します。貼り付けた基底・ECP（`document.nwchem.basis_custom`・`ecp_custom`）、J結合（`prop_spinspin`・`spinspin_pairs`）、励起状態の番号（`tddft_root`）、2つ目のスキャン座標（`scan2_*`）、フラグメント（`fragment_guess`、原子の安定IDと電荷・多重度）もプロジェクトへ保存し、内部座標の拘束の各項目は固定しない座標を `free` で示します。連鎖で待機中の計算は、まだ入力一式がないため分子・条件ごと `queue.json` に保存します。小分子のCIFから読み込んだ構造は格子定数・空間群・化学式・読み込んだ範囲をメタデータ（`crystal`）に、配位子の部品（組込みとマイ部品）はη配位の原子群（`hapto`）と金属の位置（`center`）を持ちます。xTB実行ファイルと書き出しの設定はアプリ設定に保存し、プロジェクトには保存しません。1.0.0で実行したジョブも、ジョブフォルダーにデータベースが残っていれば再開できます。1.0.0で実行中のまま残った記録には見張り用のプロセスがないため、履歴からは停止できません。配座セット、エネルギー比較、スペクトル表示条件は、それぞれの画面から別のJSONファイルへ明示的に保存してください。スペクトル表示条件は元の結果ファイルと結び付いています。

### 確認した範囲

Linuxで1.1.0のビルド、全16系列のCTest、日英ドキュメントのサイト生成を確認しました。物性の読込と規約はNWChem 7.3.1の小分子の実計算（ラマン・ESR・ECD・ORD・ESP／電場CUBE）で確認しています。再開もNWChem 7.3.1の小分子の実計算（反復上限で止めた「最適化 → 振動数」の続行、数値Hessianの続行、振動数計算のHessianを使う遷移状態探索、`freq` の `reuse`）で確認しました。ウィンドウを閉じた後の継続と再接続は試験用プロセスで確認しています。AppImageのビルド環境（Ubuntu 24.04・Qt 6.4）でもビルドと全16系列のCTestが通り、作成したAppImageで、セッションを終えた後の計算の継続・追跡・停止を確認しました。WindowsとmacOSでは未確認です。NEBはNWChem 7.3.1で、MolFormaが生成したHCN → HNC（HF/STO-3G、像5、3ステップ）の入力の実行とログの読込を確認しました（収束まで進めた計算は未確認）。連鎖は試験用プロセスで、xTBは試験用の代替プログラムで確認しており、実際のxtbでは未確認です。図と動画は、Linuxの画面（VTK）と画面なし（QPainter）の両方で倍率・背景を、GIFはQtの読込みとImageMagickで、MP4はffmpeg 9で確認しました。NEB・連鎖・xTB・図と動画は、AppImageのビルド環境（Qt 6.4）では未確認です。小分子のCIFはCODの5件（分子が対称心をまたぐもの、化学式単位に対イオン・リチウムを含むものなど）で、PubChemからの取得は実際のサービス（3D構造があるアスピリン、3D構造のないステアリン酸とフェロセン、見つからない名前）で確認しました。多座配位子・η配位はGUIでフェロセン、Fe(tacn)(dien)、Ni(ポルフィナト)、Ru(terpy)₂、Co(EDTA)を組んで、溶媒和殻はトリプシン（1,712原子）のまわりに水1,000分子を約1秒で置けることを確認しました。これらはAppImageのビルド環境（Qt 6.4）では未確認です。計算条件の拡張は、NWChem 7.3.1でMolFormaが生成した入力の実行と結果の読込で確認しました（水のHだけにSTO-3Gを貼り付けたB3LYP/6-31G*、エタンとCH₃FのJ結合、エチレンの最低一重項励起状態の最適化、H₂O₂の追加した二面角、2つのメタンのフラグメント初期軌道、エタンの3×3点の2次元スキャン）。いずれも小分子で、AppImageのビルド環境（Qt 6.4）では未確認です。小基底の動作確認であり、実験との定量的一致を検証したデータではありません。各OSのインストール手順にある過去の検証記録は、その記載バージョンでの記録です。
