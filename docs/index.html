NWCHEM · MOLECULAR EDITOR

分子を組み、計算し、
結果を確かめる。

MolFormaは、量子化学計算プログラムNWChemのためのデスクトップアプリです。部品を置いて分子を組み、計算条件を選んでNWChemを実行し、最適化した構造や振動・軌道・スペクトルまでを1つの画面で確かめられます。

題材から選ぶ実習 機能と操作 GitHubでソースを見る
  • Qt6 / C++20
  • 日本語・英語
  • MCPサーバー内蔵
  • 実行時にPython不要
  • GPL-2.0-or-later

画面の流れのとおりに進める

ヘッダーに並ぶ番号付きのタブが、そのまま作業の順番です。

  1. 1分子部品・SMILES・構造ファイルから分子を組み、力場で形を整える
  2. 2計算条件手法・基底・電荷・計算目的を選び、組合せを検査する
  3. 3実行設定NWChemの実行ファイル・MPIプロセス数・ジョブの保存先
  4. 4入力プレビュー生成したNWChem入力を確かめ、保存する
  5. 結果ビューア構造・振動・軌道・スペクトル・反応経路を確かめる
  6. 履歴過去の計算を比べ、分子と条件を再利用する

1 分子

部品を置くだけで、計算できる分子に

原子・骨格・置換基・配位子・アミノ酸の部品をクリックで置き、結合の種類や距離・角度・二面角を数値で指定します。編集は候補として表示し、確かめてから確定します。

  • 配位中心と配位形状、二座配位子、酸化数に合わせた全電荷
  • 配列からのペプチド（末端キャップ・側鎖の状態）と残基の置換
  • 立体（R/S・E/Z）の記録と反転、同位体、外部点電荷、自作の部品
  • SMILES、XYZ・MOL・SDF・PDB、NWChem・Gaussian入力からも始められる

2 計算条件 · 4 入力プレビュー

選んだ条件から、検査済みのNWChem入力を

手法・基底・電荷と多重度・計算目的を選ぶと、電子数と組合せを検査し、座標から task までそろった入力を生成します。入力プレビューでは、各行がどの設定から来たかをたどれます。

  • HF・DFT・MP2・CCSD(T)
  • 構造最適化・振動数
  • 遷移状態探索・IRC
  • 座標スキャン・拘束
  • TDDFT
  • COSMO・SMD
  • BSSE補正
  • ZORA・DKH・X2C
  • Mulliken・ESP・NMR・分極率

結果ビューア

計算の結果を、その場で確かめる

NWChemをローカルで実行・停止し、進み具合とログを表示します。終わった計算は結果ビューアで開き、最適化した構造を次の計算に取り込めます。

  • 最適化の経過と収束、エネルギーの一覧とΔE
  • 振動のアニメーションとIRスペクトル、熱化学
  • 分子軌道・電子密度の等値面（CUBE・MOLDEN）
  • 励起状態と吸収スペクトル、スキャン・IRCの経路

履歴

保存した計算を日ごとに一覧し、組成・手法・基底が同じジョブどうしのエネルギー差（ΔE）を並べます。計算に使った分子と条件は、そのまま再利用できます。

AIからの操作（MCP）

MCPサーバーを内蔵しています。Claude CodeやCodexに登録すると、分子の編集から計算・結果の確認までを言葉で頼めます。NWChemの実行ファイルや読み書きする場所は、利用者が決めた範囲に限られます。

入手とビルド

ソースコードはGitHubで公開しています。次の開発パッケージを入れてビルドします。計算には、別にNWChem（MPI版では対応するMPIランチャー）が必要です。

必須
Qt6（Widgets、6.4以上）、Eigen3、Open Babel 3、CMake 3.21以上、C++20コンパイラ
任意
RDKit C++（立体判定・残基認識）、VTK 9.1以上（3D描画）
READMEの手順を見る 
# ソースの取得とビルド
git clone https://github.com/hnakada123/MolForma.git
cd MolForma
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
./build/molforma
