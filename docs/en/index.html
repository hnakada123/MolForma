NWCHEM · MOLECULAR EDITOR

Build a molecule, calculate it, check the results.

MolForma is a desktop app for the quantum chemistry program NWChem. Build a molecule by placing parts, choose the calculation, run NWChem and check the optimized structure, vibrations, orbitals and spectra, all in one window.

1 Molecule

Place parts, get a molecule ready to calculate

Place atoms, skeletons, substituents, ligands and amino acids with a click, and set bond types, distances, angles and dihedrals by value. Edits are shown as candidates and confirmed after you check them.

  • Coordination centers and geometries, bidentate ligands, the total charge following oxidation numbers
  • Peptides from a sequence (terminal caps, side-chain states) and residue mutation
  • Recording and inverting stereo (R/S, E/Z), isotopes, external point charges, your own parts
  • Start from SMILES, XYZ, MOL, SDF or PDB files, or NWChem and Gaussian inputs
The “1 Molecule” window

2 Calculation · 4 Input preview

From your choices to a checked NWChem input

Choose the method, basis, charge and multiplicity and the task; MolForma checks the electron count and the combination, and writes a complete input from the coordinates to the task. The input preview traces each line back to its setting.

  • HF, DFT, MP2, CCSD(T)
  • Optimization, frequencies
  • Transition states, IRC
  • Scans, constraints
  • TDDFT
  • COSMO, SMD
  • BSSE correction
  • ZORA, DKH, X2C
  • Mulliken, ESP, NMR, polarizability
About “2 Calculation”

Result viewer

Check the results right where you work

Run and stop NWChem locally and follow its progress and log. Open a finished calculation in the result viewer and bring the optimized structure into the next calculation.

  • The optimization and its convergence, energies and ΔE
  • Animated vibrations, IR spectra and thermochemistry
  • Isosurfaces of molecular orbitals and densities (CUBE, MOLDEN)
  • Excited states and absorption spectra, scan and IRC paths
About the result viewer

History

Saved calculations are listed by day, with energy differences (ΔE) between jobs of the same composition, method and basis. The molecule and settings of a calculation can be reused as they are.

About history

Operated by AI (MCP)

MolForma has a built-in MCP server. Registered in Claude Code or Codex, it takes requests in words, from editing a molecule to running a calculation and checking its results. The NWChem executable and the places it reads and writes stay within what you allow.

Getting and building

The source code is on GitHub. Install the development packages below and build it. Calculations also need NWChem (and, for MPI builds, the matching MPI launcher).

Required
Qt6 (Widgets, 6.4 or later), Eigen3, Open Babel 3, CMake 3.21 or later, a C++20 compiler
Optional
RDKit C++ (stereo and residue recognition), VTK 9.1 or later (3D rendering)
Steps in the README 
# Get the source and build
git clone https://github.com/hnakada123/MolForma.git
cd MolForma
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
./build/molforma
