# 題材から選ぶ実習（分子を組んで計算するまで）

MolFormaの画面操作だけで分子を組み、NWChemで計算して結果を確かめるまでを、題材ごとに1本の手順で通す実習です。作りたい分子に近い題材を選ぶと、そこで使う機能（原子と結合、骨格・置換基、配位中心と配位子、配列からのペプチド、立体の指定、点電荷、BSSE補正、遷移状態探索、計算結果の取り込み、同位体、マイ部品など）をひととおり試せます。

各ページの計算は、2026-10-26にNWChem 7.3.1（Linux、MPI 2〜8プロセス）で実際に実行した結果を載せています。NWChemの版や並列数によって、エネルギーの末尾の桁や最適化のステップ数は変わることがあります。

## この実習の使い方

- **機能から引く**: 画面の部品ごとの説明は「[機能と操作](features.md)」に、画面・タブごとのページに分けてあります。どのボタンが何をするかを調べるときに使います。
- **題材から引く**: このページの16題材です。新規の分子から（または構造ファイル・計算結果から）始めて、計算条件の設定、計算の実行、結果の確認までを通します。
- **各ページの構成**: 「作るもの」→ 手順 → 計算条件 → 計算と結果 →「うまくいかないとき」の順です。手順の中のかぎ括弧（「全体整形」など）は画面に表示される名前です。
- **練習データ**: 完成したプロジェクト（`.kgui.json`）を、各題材の表の「練習データ」にリンクしています（リポジトリの `docs/recipes/samples/`）。Webのマニュアルではリンクからダウンロードでき、アプリの「操作ガイド・マニュアル」ではリンクをクリックすると保存先を選んでそのまま開きます（部品ファイル `.kpart.json` は「マイ部品」に読み込みます）。途中から始めたり完成形と見比べたりできます。実行設定（NWChemの実行ファイル・ジョブ保存先など）は含めていないので、計算の前に「3 実行設定」を確認してください。

### 組み立てた構造と計算結果を区別する

部品を置いた直後や「全体整形」の後の構造は、計算の**初期構造**です。「全体整形」はOpen Babelの力場（MMFF94・UFF）で形を整える操作で、NWChemの構造最適化とは別です。最適化した構造を次の計算に使う場合は、「結果ビューア」の「分子へ候補として適用」で取り込みます（[題材14](recipes/reuse_result.md)）。

計算の全電荷と多重度は「2 計算条件」の「電荷・スピン」で決めます。原子の形式電荷（「属性」ページ）は水素補完などの構造の準備に使う値で、全電荷とは別に管理します。残基・断片・配位中心・配位子の追加では、変更前の全電荷が構造から見込まれる値（形式電荷の合計、配位中心は酸化数）と一致していれば、新しい値に合わせます。多重度は推測しないので、ラジカルや開殻の金属を含む分子では自分で指定します。

## この実習にない題材

MolFormaが作るのは有限個の分子（と外部点電荷）で、計算はNWChemの分子向けの機能を使います。次のものは対象外です。

- FMO（フラグメント分子軌道法）やSAPT0（エネルギー分解）。NWChemで計算できないため、タンパク質の活性部位を断片に分けて計算する題材は載せていません。PDBの読込・診断・修復は[「1 分子」の右側のページ](features/molecule_pages.md)の「残基」ページを参照してください。
- 結晶・周期系、表面、ポリマーの自動生成、溶媒ボックスの自動発生、2つの構造から経路を作るNEB。溶媒は手で置くか（[題材12](recipes/hydrated_sodium.md)）、連続誘電体モデル（COSMO・SMD）で扱います。

MCPクライアント（AI）から同じ操作を言葉で頼むこともできます。ツールの一覧と例は「[MCPサーバー](mcp.md)」にあります。
