# 「結果ビューア」

スペクトルを表示する場合は[分光](#nmr通常ラマン溶液esrのスペクトル)と[ECD・ORD](#ecdord)、表面の色付けや双極子は[物性3D・断面](#物性3d断面)、次の計算へ進む場合は[再計算の準備](#結果の構造から再計算を準備)を参照してください。

上部のバーの「開く…」で単独の結果ファイルを読み込むか、その ▾ の「ジョブフォルダーを開く…」で同じフォルダーの対応ファイルを一覧にします。バーには左からジョブフォルダー名（ツールチップに全体のパス）、ファイル一覧、形式（NWChem 出力・MOLDEN・CUBE・XYZ）、NWChemログが正常終了していれば「正常終了」を示し（正常終了の記録がないときとエラーのときは、詳細タブの上の警告だけで示します）、右に「開く…」「再読込」「中止」「分子と比較」「分子へ候補として適用」「書き出し」を置きます（何も開いていない間は「開く…」だけ）。ウィンドウが狭く1行に収まらないときは、「分子と比較」「分子へ候補として適用」「書き出し」をアイコンだけにします（名前はツールチップ）。読込中・中止・エラー・「分子と比較」の結果は右側の詳細タブの下のメッセージ欄に表示し、ないときは欄を閉じます（欄の開閉で詳細タブの上端は動きません）。実行パネルの「結果ビューアへ」からは、表示中のジョブフォルダーを開きます。`output.out`があれば優先して選び、なければ一覧の最初の対応ファイルを開きます（XYZだけのフォルダーも開けます）。フォルダーの走査は直下のみです。加えて、MolFormaの`run.json`に記録したCUBE・MOLDENの出力先（最大2個）を一覧に含めます。permanentのサブフォルダーや絶対パスの出力も選べますが、再帰走査はしません。

**図1** エタノールの「最適化 → 振動数」のジョブフォルダーを開いたところ。「概要」のカードを押すと、該当する詳細タブを開きます。

ファイル一覧はログ・構造・CUBE・MOLDENの種類ごとに区切って並べます。NWChemの `freq animate` が出力する振動ごと・ステップごとのXYZ（`…m-001.s-001.xyz` 等）は「振動アニメーション: モード N（K枚）」の1項目にまとめ、選ぶと全ステップをつないだ構造列として読み込みます（3Dビュー下の再生ボタンで動かせます）。ファイル一覧で別のファイルを選ぶとすぐに読み込みを開始し、完了後に3Dビューと詳細を更新します。読込中に選び直すと前の読み込みを中止し、最後に選んだファイルを表示します。失敗した場合は前の表示を保持して詳細タブの下のメッセージ欄に理由を示します。

振動アニメーションの結合も取消可能な読込プロセス内で行います。「再読込」は元のXYZ群を読み直し、ステップの追加・削除も反映します。読込中に元ファイルの内容や一覧が変わった場合は結果を採用せず、前の表示を保持します。結合サイズの上限は64 MiBです。

表示は編集中の分子から独立しています。ファイル読込、回転・拡大縮小、フレーム切替、振動再生でプロジェクト・固定原子・候補・Undo履歴を変更しません。結果の座標はすべて倍精度のÅへ変換し、結合は原子間距離から推定します。ビューアの結果・等値面・再生状態はプロジェクトに保存しません。既存の結果参照フィールドは従来どおり保持します。

3Dビューは「1 分子」と同じ構成です。右上の「+X」「+Y」「+Z」「全体を表示」「回転」「表示」（ラベル）で視点とラベルを操作します。「回転」は「左右回転」「上下回転」「画面内回転」のスライダー（−180〜180度）をポップアップで表示し、スライダーはマウス操作や+X/+Y/+Zに追従します。構造や等値面の表示方向だけが変わり、保存する構造の座標には影響しません。左上には表示中の内容（構造の番号と出典の行・タイトル、分子軌道の名前・エネルギー・等値、振動モード、CUBEのデータと格子）を示します。

3Dビューの下の操作欄は、表示中の内容に合わせて切り替わります。構造列では「最初の構造」「再生」「最後の構造」、構造番号、タイムライン（クリック・ドラッグ・矢印キーで選択）を置き、座標スキャン・IRCの点では各点のエネルギーを線で描いて最小値基準のΔE（kcal/mol）を添えます。MOLDENの分子軌道では軌道の移動ボタンと「HOMO」「LUMO」、振動ではモードの再生、振幅、変位の矢印、書き出しと、構造列に戻る「×」を置きます。操作欄の高さはページを切り替えても変わらないため（狭い幅ではまとまりごとに2行へ折り返します）、3Dビューの大きさは動きません。

読込中・完了・中止・エラーのメッセージは、結果ビューア下部の高さを固定した欄に表示します。軌道の切り替えでメッセージの行数が変わっても、3Dビューや矢印ボタンは上下に動きません。同じファイルの軌道を切り替える読込はこの欄を開かず、「軌道」タブ下部の「表示中」の行を「読込中」に変えるだけなので、準位図と一覧の大きさも変わりません。長いパスやエラーの全文は欄内をスクロールして確認・コピーできます。

振動はモード表かIRスペクトルの棒で選び、3Dビュー下の再生ボタンで再生します。負の振動数は虚振動です。−10 cm⁻¹未満の虚振動は有意なものとして赤で示します（それより小さい負の値は、振動数がほぼ0のモードの数値誤差であることが多いためです）。振幅は原子の最大変位を指定値へ規格化した表示用の値であり、再生速度は実際の振動数に比例しません。変位のないモードは数値表示のみです。バーの「書き出し」の「表示中の構造をXYZで書き出す…」は選択したフレーム、振動表示中は振動の基準構造をXYZへ書き出します。「3D表示を画像で書き出す…」は現在の構造画面を倍率・背景を選んでPNGへ、「構造列を動画・連番画像で書き出す…」は構造列をGIF・MP4・PNG連番へ書き出します（[図と動画の書き出し](#図と動画の書き出し)）。

CUBEは正の等値面を赤、負の等値面を青で表示します。等値、データ番号、正負の表示、不透明度を変更できます。値そのものはファイルに記録された単位を使い、電子密度・軌道・静電ポテンシャル等を自動判定しません。座標・格子の単位はNWChemが出力するGaussian CUBEのBohrを使用します。負の格子数をÅ指定として使う拡張や、原子番号0のダミー中心は拒否します。各軸は2点以上必要です。等値面はmarching cubesで生成します。立方体の各面で等値面が辺を横切る点を結び、2通りに結べる面は双線形補間の鞍点の値（asymptotic decider）で決めるため、隣り合う立方体の面と一致し、面に隙間ができません。辺上の点は1回だけ求めて隣の三角形と共有し、VTKでは共有した頂点のメッシュとして保持してOpenGLで描きます（以前のmarching tetrahedraと比べて三角形数は約3分の1）。QPainter経路では奥行き順に描くため、透過面の交差・重なりは近似表示です。詳細は「[3D描画](rendering.md)」を参照してください。

読込・等値面生成は同じC++実行ファイルの別プロセスで行い、中止・別ファイルへの切替・ウィンドウ終了で停止します。失敗・中止では前の結果を保持します。読込前後でサイズ・更新日時・参照先が変わったファイルは採用しません。実行途中のログは「再読込」で更新してください（ログの自動追尾は実行パネルと「履歴」で行います）。「3 実行設定」で「終了したら結果ビューアに読み込む」を有効にしていると、計算の終了時にそのジョブフォルダーを読み込みます。「正常終了マーカーあり」は全taskの成功や収束を保証しません。最適化の収束・計算のエネルギー・虚振動の数などは「概要」に示します（MCPの `get_app_state` の結果の `message` には、画面なしモードでも、終了状態に添えて1行で返します。虚振動は「虚振動 2個（−10 cm⁻¹未満 1個）」のように全体の数と有意な数を示します）。NWChemログに正常終了の記録がない場合やエラーを検出した場合は、詳細タブの上に警告を表示し、「ログの末尾を表示」で「元ファイル」の末尾へ移動します。詳細タブ（エネルギー・軌道・振動・最適化・励起状態・経路・スキャン・物性・CUBE / 等値面・元ファイル）は、読み込んだファイルにデータのあるものだけを表示し、タブ名に件数（記録・軌道・並進回転を除く振動・最適化ステップ・励起状態・経路の点）を添えます。何も開いていないときは「概要」に開けるファイルの説明を表示し、3D画面の操作（+X/+Y/+Z・全体を表示・回転・表示）と3D画面の下の構造の切替は表示しません。表示・回転・計測の操作は構造を開くまで無効です。エネルギーと構造はそれぞれ出力順で表示し、最適化ステップとの1対1対応を仮定しません。「計算のエネルギー」はログをtaskごとに区切って求めた値で、最後のtaskの値です。振動数のtaskでは参照構造の値（数値Hessianはその後に変位構造のエネルギーを出力するため）、BSSE補正では補正後の値を使います。

読込上限は1ファイル128 MiB、1構造2000原子、2000構造かつ合計20万原子、CUBE200万格子点・全データ400万値、等値面50万三角形です。上限を超える場合は明示的にエラーにします。等値面が大きすぎる場合は「CUBE」の等値を変更してファイルを開き直すか、小さな格子を使用してください。「元ファイル」欄は末尾128 KiBを表示します。

「概要」は、最後の構造の組成式と、計算のエネルギー、構造最適化（収束・ステップ数・最終ステップが満たす判定の数）、虚振動（数と値、そのうち−10 cm⁻¹未満の数）、HOMO–LUMOギャップ（eV、スピン別）、双極子モーメント（Debye）、励起状態、座標スキャン・IRC、等値面、構造列をカードで示します。カードを押すと該当する詳細タブを開きます。続けて温度ごとの熱化学の補正値とGibbs補正 G = H − TS（MolFormaの算出値。電子エネルギーに加えて使用）、ほかの結果（BSSE・溶媒和・分極率など）、ログの状態と警告、同じフォルダーの結果ファイル（「開く」で切り替え）を表示します。熱化学の数値はNWChemの出力（調和振動子・1 atm）のままで、振動数スケール・準RRHOのエントロピー・1 mol/Lの標準状態の補正は「履歴」の[熱補正・反応エネルギー図](history.md#熱化学の補正と速度定数)で適用します。「最適化」タブは最終ステップのGmax・Grms・Xrms・Xmaxを収束閾値と並べた判定、最終ステップ基準のエネルギー変化（kcal/mol）とGmax・Grmsの対数グラフ（破線は収束閾値）、ステップ表（閾値を満たした値を色付きで表示）を表示します。変位（Xrms・Xmax）は最初のステップでは判定せず、概要の判定の数にも含めません。「励起状態」タブは状態の一覧と、振動子強度をガウス関数（半値全幅をeVで指定）で広げた表示用の吸収スペクトルを波長またはエネルギー軸で表示します。一覧の「主な遷移」は、各状態で重みが最大の占有→仮想軌道の対を `HOMO−1 → LUMO（62%）` のように示します。ログの電子数（なければ軌道解析）からHOMOの番号がわかるときはHOMO・LUMOを基準にした名前、わからないときは軌道番号（`12 → 14`）です。非制限計算ではα・βを添え、それぞれのスピンのHOMOを基準にします。この列のあるログでは、どの状態でも同じ「対称」の列、値のない「<S²>」の列、行番号を表示しません。列が狭くて読めないときは、セルにポインターを置くと全体を表示します。状態を選ぶと、NWChemがその状態について出力した対（係数の絶対値が0.05を超えるもの。多い場合は係数の大きい50個）の軌道番号・X・Yの係数・重みを一覧の下に表示します。重みは対ごとの X² − Y² を、出力された対の合計で割った百分率です。出力されない小さな寄与を含まないので、実際よりやや大きくなります。Tamm–Dancoff近似（CIS）にYはありません。同じジョブにMOLDENファイルがあれば、軌道番号のダブルクリックでその軌道の形を表示します（「仮想軌道」の列では仮想軌道、ほかの列では占有軌道。MOLDENがなければ「軌道」タブでその軌道の行を選びます）。実行中のログなどで出力が途中の状態には、寄与を表示しません。ログの軌道はエネルギーと占有数だけで、形状の表示にはMOLDENが必要です。

**図2** 「最適化」タブ。最終ステップの4つの収束判定、エネルギーと勾配のグラフ（破線は閾値）、ステップの表です。

「分子へ候補として適用」は、表示中の構造（振動の再生中は基準構造）の座標を「1 分子」の分子へ候補として適用し、画面を「1 分子」に切り替えます。原子の数と順番・元素・ゴーストが一致する結果だけを受け付け、固定原子が結果で 0.001 Å を超えて動いている場合は拒否します（座標系の異なる結果を防ぐため）。原子ID・結合・残基・計算条件は変えず、「変更を確定」までは分子を変更しません。RMSDと最大変位をステータスバーに表示します。

「経路・スキャン」タブは座標スキャンの各点（値・エネルギー・最小値基準のΔE / kcal mol⁻¹）、IRCの各点（遷移状態を0とし、前進方向を正・後退方向を負とした反応座標 s / amu½·Bohr、遷移状態基準のΔE）、またはNEBの経路の像（始点からの経路の長さ / Å、始点基準のΔE）を表とグラフで表示し、行を選ぶとその点の構造を表示します。2次元スキャンでは、表に2つの座標の値を並べ、グラフの代わりに、横軸を座標1・縦軸を座標2として各点のΔE（最小値基準、kcal mol⁻¹）を色で表した図（暗い色ほど低い）と色の目盛を表示します。図の点をクリックすると、その点の行と構造を選びます。NEBは、`print_shift` でログに出力された最後の経路を読み、各像のエネルギーはその経路と同じステップの全桁の値を使います。表の下にそのステップの番号、収束・未収束と、最後のステップのGmax・Grmsを閾値と並べて示します（未収束はエラーではなく、ログの警告に示します）。経路の長さは隣り合う像の原子座標の差（質量加重なし）の和です。「最高点を選択」は両端を除いてエネルギーが最も高い点を選び、「この点から遷移状態探索を準備」は、このジョブの条件を計算目的「遷移状態探索 → 振動数」、計算名の末尾に `_ts` を付けて読み込み、表示中の点の構造を候補にします（「再計算を準備」と同じく保存済みのジョブで使えます）。「物性」タブは原子ごとのMulliken・ESP・RESP電荷とNMR遮蔽定数・異方性の表と、分極率（a.u.とÅ³）・BSSE補正・溶媒和エネルギーを表示します。「物性 → Mulliken電荷」を計算したログでは、原子ごとの原子価と、原子対の結合指数の表も表示します。結合指数の表は、絶対値が0.05以上の対を大きい順に、最後の構造での原子間距離とともに並べます（「すべての原子対を表示」で全部の対）。行を選ぶと、その2原子を3Dビューで選択し、距離を計測の欄に表示します。結合指数はNWChemがMulliken解析で出力する「Bond indices」（Mayerの結合次数）で、原子価は閉殻ではその原子の結合指数の和に等しく、開殻ではそれより大きくなります。どちらも基底関数に依存し、diffuse関数を含む基底では信頼できません。原子対が2万を超える分子（201原子以上）では、絶対値が0.05未満の対を読み込みません。「物性 → NMRのJ結合」を計算したログでは、原子の組ごとのJ結合（Hz、NWChemが使った核種と、最後の構造での原子間距離）の表も表示し、行を選ぶとその2原子を3Dビューで選択します。NMRは絶対遮蔽定数で、化学シフトには同じ条件の基準物質の値との差が必要です。

「エネルギー」タブは全エネルギー（Eh、小数10桁）と、選んだ行を基準にしたΔEをkcal/mol・kJ/mol・eV・Hartree・cm⁻¹で表示します（既定の基準は最後の行）。手法の異なる行どうしの差には意味がありません。「振動」タブは振動数の絶対値が最も小さい6個（直線分子は5個）を「並進・回転」とし、それ以外の負の振動数を「虚振動」と表示します（3N個のモードがそろう場合）。並進・回転は既定で一覧から省き（IR強度は「—」）、「並進・回転のモードも表示」で表示します。概要の虚振動の数と値もこれを除いて数えます。モード表のIR強度は、最も強いモードに対する長さの棒でも示します。IRスペクトルは並進・回転と虚振動を除いたIR強度を、指定した半値全幅のローレンツ関数で広げた表示用の曲線で、波数の大きい側を左に描きます。棒をクリックするとそのモードを選び、選択中のモードの棒を強調します。3Dビュー下の「矢印」は選択したモードの変位を基準構造に矢印で重ね（最大の矢印は振幅の3倍）、「書き出し」の「振動を動画・連番画像で書き出す…」は1周期を24枚のGIF・MP4・PNG連番、「振動をXYZ（複数構造）で書き出す…」は24フレームのXYZに書き出します。

## MOLDENから分子軌道を表示する

NWChemのログの「軌道」タブは軌道エネルギーだけを示し、番号はNWChemの軌道番号（ログに一部の軌道しかなくてもMOLDENと同じ番号）です。同じジョブフォルダーにMOLDENファイルがあれば、「形を表示」または軌道の行のダブルクリックでそのMOLDENを開き、同じ軌道（スピンとNWChemの番号が一致する軌道。未選択ならAlphaのHOMO）を表示します。MOLDENは「2 計算条件」の「軌道・出力ファイル」にある「MOLDENファイルを出力」で出力します。`[Atoms]`・`[GTO]`・`[MO]`を含むMOLDENを開くと、AlphaのHOMOを自動表示し、「軌道」タブへ移動します。Alphaの占有軌道がなければBeta、占有軌道がなければ最初の軌道を選びます。HOMOは占有数が正の軌道のうち最高エネルギー、LUMOは空軌道のうち最低エネルギーとして、スピン別に判定します。縮退軌道や任意の軌道も一覧から選べます。

![MOLDENファイルを開いたところ。3DビューにHOMO（Alpha 13番、−7.117 eV）の等値面が赤と青で出て、右の「軌道」タブに準位図と軌道の一覧がある](images/results/04_orbital.png)

**図4** 同じジョブのMOLDENファイル（エタノールのHOMO）。準位図または一覧で軌道を選ぶと、表示を切り替えます。

- 「軌道」タブ左の準位図は、スピンごとにHOMOの下とLUMOの上の6準位まで（HOMOの25 eV下からLUMOの15 eV上までの範囲）を描きます。占有軌道は電子の矢印付きの線、空軌道は枠で示し、ほぼ同じエネルギーの準位（縮退軌道）は横に並べます。1スピンの場合はHOMO・LUMOの名前とエネルギー、HOMO–LUMOギャップを添えます。範囲外の軌道は個数だけを示します（内殻軌道で価電子の準位が詰まらないように）。準位をクリックすると一覧と同じく軌道を選び、ポインターを重ねると番号・エネルギー・占有数を表示します。ログの軌道にも同じ図を表示します。一覧は、スピンが1種類ならスピン列を、対称性ラベルが同じなら対称性列を省きます。
- 「HOMO」「LUMO」（3Dビュー下の操作欄）は選択中のスピンの軌道を表示します。一覧の行をクリックするか上下キーで選ぶと、すぐに表示を切り替えます。読込中に選び直した場合は最後に選んだ軌道を表示します。軌道番号は「番号」列だけに表示し、Alpha/Betaごとに1から数えます。
- 3Dビュー下の操作欄に「先頭・10戻る・1戻る・1進む・10進む・末尾」の矢印ボタンがあります。表示中の軌道を基準に一覧の順序で移動し、Alpha/Betaの境界も越えます。10軌道分に満たない場合は先頭または末尾で止まります。表示中のスピンと番号を「1戻る」と「1進む」の間に、HOMO・LUMOからの位置（HOMO−1など）とエネルギーを3Dビュー左上に示します。
- 正の軌道関数を赤、負を青で描きます。全体の位相の符号は任意です。等値の既定は±0.03 bohr⁻³ᐟ²で、値を変えて再表示できます。正負の表示と不透明度は「CUBE / 等値面」で調整します。
- 格子は原子座標の各軸の最小・最大に3 Åを加えた範囲で、最も長い辺を40分割し、ほかの軸も同じ間隔にします（MolFormaが出力するCUBEの既定と同じ格子）。16〜100分割で調整できます。入力作成用のCUBE格子設定とは独立した閲覧時の設定です。
- 基底係数の正規化は、収縮関数の解析的な自己重なり積分から標準MOLDENとNWChem規約を判定し、使用した規約を表示します。標準はプリミティブの正規化因子を掛け、NWChem規約では係数内の因子を使い、収縮関数を正規化します。判定できない場合は形状を表示せず、利用者が規約を選んで再表示します。
- NWChemの`molden_norm none`では、有効なファイルでも収縮関数が未正規化のため自動判定できない場合があります（cc-pVQZで確認）。この場合は読込側の正規化で「標準MOLDEN」を選びます。外部ソフトへの受け渡し時の出力規約は「[CUBE・MOLDEN出力](advanced.md)」を参照してください。
- 等値と格子分割数はEnterキーまたは入力欄からの移動で確定すると、選択中の軌道に反映します。正規化は選択を変えると反映します。
- s・p・sp、Cartesianの6d/10f/15g、実球面調和関数の5d/7f/9gに対応します。MOLDEN規約の基底順序を使用します。STO・h以上の基底・複素軌道や、基底／係数の不足・不整合では形状を表示できません。構造・軌道情報は可能な範囲で表示し、理由を示します。

軌道評価と等値面生成はネイティブC++の別プロセスで行い、NWChemやPython、CUBEの生成は不要です。読込中止・古い結果の棄却は通常の結果読込と共通です。表示中の軌道番号を明示し、再計算失敗時は前の表示を保持します。MOLDENの別の構造フレーム・振動へ切り替えたときは、軌道の基準構造と異なる位置へ面を重ねません。編集中の分子・Undo・元ファイルは変更しません。

軌道計算ではGaussianの指数関数と座標のべき乗を各軸で再利用し、格子密度を下げずに高速化しています。格子はx方向の面ごとに複数のスレッドで分担して計算します（各格子点の値は分担に関係なく同じになります）。表示済みの等値面は約64 MiBを上限としてメモリに保持し、同じ軌道・等値・格子分割数・正規化で戻ると再計算せずに表示します。上限を超えると古いキャッシュから解放します。ファイルのパス・参照先・サイズ・更新日時・メタデータ変更日時が変わった場合や、ファイルを開き直した場合、「再読込」時は破棄します。未表示の軌道やキャッシュから解放された軌道には計算時間がかかります。このほか、読み込んだMOLDEN・CUBEの読み取り結果（MO係数・格子の値）と計算した軌道の格子の値を、ウィンドウを閉じるまで一時フォルダーに保持します（約512 MiBまで）。別の軌道・等値・データの表示ではファイルを読み直さず、同じ軌道の等値の変更では軌道を計算し直しません。同じファイルかどうかは上と同じ情報で判定し、「再読込」ではファイルから読み直します。

上限は4000基底、10000プリミティブ、1シェル100プリミティブ、MO係数400万個です。格子点数×プリミティブ数が10億を超え、各プリミティブの値が0にならない範囲で数えた計算量も10億を超える場合は、分割数を減らすよう案内します。全電子密度や静電ポテンシャルの再計算は未対応です。全エネルギーはMOLDENの`[GEOCONV]`に値がある場合のみ表示し、通常のNWChem計算の全エネルギーは`output.out`で確認します。

規約の参照: [MOLDEN形式](https://www.theochem.ru.nl/molden/molden_format.html)、[NWChemのMOLDEN正規化](https://nwchemgit.github.io/Properties.html#moldenfile)。

## CUBEの差・和（差電子密度）

「CUBE / 等値面」タブの「CUBEの差・和を作る…」で、表示中のCUBEと同じ格子のCUBEに係数を掛けて足し合わせ、新しいCUBEとして保存して表示します。結合による電子の偏りを見る差電子密度 ρ(AB) − ρ(A) − ρ(B) は、複合体のCUBEに +1、各部分のCUBEに −1 を指定します。

1. 複合体と各部分の計算で、「2 計算条件 → 軌道・出力ファイル」の「CUBEファイルを出力」（全電子密度）をオンにし、X・Y・Zの範囲と分割数を同じ値にして実行します。各部分は複合体と同じ座標のまま（部分の原子だけを残して）計算します。
2. 複合体のCUBEを開き、「CUBE / 等値面」の「CUBEの差・和を作る…」を押します。1行目に表示中のCUBEが係数 +1 で入ります。
3. 「CUBEを追加…」で各部分のCUBEを選びます（係数は −1 で入ります。必要なら変更します）。
4. 保存先を確かめて「作成して表示」を押します。

- 組み合わせられるのは、格子点数・原点・間隔が同じCUBEだけです（原点10⁻⁴ Å、間隔10⁻⁵ Åまでの違いは同じとみなします）。範囲を自動で決める既定の格子は分子の座標から作るため、構造が違うと一致しません。補間はしません。
- 原子は1行目のCUBEのものを書き、値は各ファイルの選んだデータ（1行目以外は最初のデータ）を使います。CUBEは2〜16個まで、係数は絶対値10⁶以下です。2行目に組み合わせ（`+1 ab.cube -1 a.cube -1 b.cube`）を記録します。
- 計算は結果の読込と同じ別プロセスで行い、中止できます。組み合わせるファイルを保存先にはできません。既にある保存先は確認してから置き換えます。
- TDDFTの励起状態と基底状態の差は、NWChemの差密度として直接出力することもできます（[励起状態の密度を出力する](advanced.md#励起状態の密度を出力する)）。

## NWChemでCUBE・MOLDENを生成する例

GUIでは「2 計算条件」の「軌道・出力ファイル」でCUBE・MOLDENの出力を有効にすると指示を自動生成します。外部で入力を手編集する場合は、SCF/DFTの軌道を計算した後に次のような指示を追加します。以下はHFで計算名が`water`、軌道ファイルが`water.movecs`、対象軌道がAlphaの5番の場合の例です。使用する計算・軌道番号・ファイル名・空間範囲に合わせて変更してください。DFTでは`task scf property`を`task dft property`へ変更します。

```text
property
  moldenfile
  molden_norm nwchem
end
task scf property

dplot
  vectors water.movecs
  limitxyz units angstrom
    -3 3 24
    -3 3 24
    -3 3 24
  spin alpha
  orbitals view; 1; 5
  gaussian
  output orbital5.cube
end
task dplot
```

`orbitals view`を省略して`spin total`を指定すると全電子密度のCUBEを生成できます。`limitxyz`の24は各方向の分割数で、格子点数は25です。正規化規約はMOLDENの利用先に合わせて選んでください。参照: [NWChem DPLOT](https://nwchemgit.github.io/DPLOT.html)、[NWChem Properties / MOLDENFILE](https://nwchemgit.github.io/Properties.html#moldenfile)、[MOLDEN形式](https://www.theochem.ru.nl/molden/molden_format.html)、[VMD CUBE reader](https://www.ks.uiuc.edu/Research/vmd/plugins/molfile/cubeplugin.html)。

## NMR・通常ラマン・溶液ESRのスペクトル

対応する出力を開くと「スペクトル」タブが現れます。棒とLorentz関数による表示用の曲線を描き、線幅は半値全幅です。表示範囲を空欄にすると自動設定します。ピーク表と曲線はCSV、図はPNG・PDF・SVGで保存できます。「表示条件を保存」は核種・基準値・線幅・範囲・重み等をJSONに保存します。同じ結果ファイルを開いて「表示条件を読込」で戻せます。パス・参照先・サイズ・更新時刻が保存時と違うファイルには適用しません。計算ログや編集中の分子は変更しません。

- **NMR**: ¹Hまたは¹³Cを選び、同じ条件で計算したTMSなどの基準遮蔽定数をppmで入力します。δ ≈ σ基準 − σ対象とし、ppmが左ほど大きい横軸に表示します。基準値は自動で推定しません。表の重みは既定1で編集できます。ピークの選択は結果の原子表示と連動します。一重項の反磁性分子を対象とします。J結合を計算したログでは「J結合で分裂させる（一次の多重線）」を選べ、「測定周波数（¹H）」（既定400 MHz）で、結合の並びが同じ（トポロジー的に等価な）核を1本にまとめ、その平均の遮蔽定数を中心に、ほかの等価な核の組（n個）とのJ結合の平均でn+1本に分けた一次の多重線を描きます（強度は二項係数）。¹Hは¹H・¹⁹F・³¹Pとの結合で、¹³Cは¹Hデカップリングとして¹⁹F・³¹Pとの結合だけで分けます。互いに等価な核どうしの結合は分裂に現れず、0.1 Hz未満の結合は無視します。ピーク表は等価な核の組ごとの1行で、「分裂（J / Hz）」に多重度（d・t・q・dtなど）と結合定数を示します。線幅は既定で約1.2 Hz相当に変わります。等価性は結合の並びだけで判定するため、ジアステレオトピックなCH₂のHなども1つにまとめます。強く結合した系（Δν ≈ J）の2次効果（屋根効果など）、分子運動・配座の平均化、実験積分値、常磁性NMRは含みません。配座の平均は「ツール → 配座セット…」の[配座平均スペクトル](molecule_pages.md#配座平均スペクトル)で行います。
- **通常ラマン**: 「2 計算条件 → 物性」で有効にし、励起波長を指定します。閉殻DFTの「振動数」または「最適化＋振動数」に対応します。後続の一点計算・TDDFT・BSSE・ゴースト中心との併用はできません。ログの活性表または`.normal`を開くとÅ⁴/amuのラマン活性を描きます。対応する振動を含むログではピークからモードを選べます。`.normal`単独には構造・変位がありません。NWChemの散乱断面積の畳込み列とは区別し、実験強度・温度補正・共鳴ラマンへの換算は行いません。
- **ESR/EPR**: 二重項・非制限DFT・ZORAで「ESRのg・Aテンソル」を有効にします。結果ではマイクロ波周波数（GHz）、線幅（mT）、含める核を選び、吸収または一次微分を表示します。核の表は原子選択と連動します。高速回転するS＝1/2溶液の一次高磁場近似です。選択した同位体を100%含むモデルであり、天然存在比混合、粉末、遅い運動、高スピンは含みません。対応する磁性同位体は¹H・¹³C・¹⁴N・¹⁷O・¹⁹F・²⁹Si・³¹P・³³S・³⁵Cl・⁷⁹Br。既定ではH・N・F・Pを含め、ほかは明示的に選択します。

ESRではNWChemのΔg（ppt）をg = ge I + 0.001 Δgに変換し、A（MHz）はA×g/geのトレースから等方値を求めます。含めた核の最大超微細分裂がマイクロ波エネルギーの10%を超える場合は表示を拒否します。スペクトルは4096ピークまでです。数値処理はMCPの`get_results`の`spectrum`・`spectrum_peaks`でも共通です。

参照: [NWChemのラマン](https://nwchemgit.github.io/Properties.html#raman)、[NWChemのEPRテンソル規約](https://nwchemgit.github.io/EPR-pNMR.html)。水の通常ラマンとメチルラジカルのEPRをNWChem 7.3.1で確認しています。

### チャートを表示・保存する

1. 計算したジョブの`output.out`などを開き、右側の「スペクトル」タブで種類を選びます。必要な物性がないログからスペクトルを推定することはありません。
2. NMRは核種と基準遮蔽定数、ESRはマイクロ波周波数と含める核を指定します。NMR・ラマン・ESR・ECDの「半値全幅」は横軸の単位（ppm・cm⁻¹・mT・eV）です。表示範囲を指定する場合は、NMRでも小さい値から大きい値の順に入力します。
3. ピーク表で対象を選び、原子・振動・励起状態との対応を確認します。NMRでは重みも編集できます。線幅や重みを変えても元ログは変わりません。
4. 「表示条件を保存…」でJSONに保存します。「CSV…」はピークと曲線、「図…」はチャートをPNG・PDF・SVGで書き出します。条件を再利用するには、保存時と同じ結果ファイルを開いて「表示条件を読込…」を使います。

![メチルラジカルの溶液ESRを一次微分で表示。マイクロ波9.5 GHz、線幅0.1 mT、H核を含めた例](images/results/05_epr.png)

**図5** 計算したg・Aテンソルから描いたS＝1/2溶液ESR。核の選択・マイクロ波周波数・線幅を指定できます。天然存在比の混合スペクトルではありません。

## 図と動画の書き出し

3D画面とグラフを、論文やスライド用の図・動画として書き出せます。

- **3D画面の画像**: 結果ビューアの「書き出し → 3D表示を画像で書き出す…」、「1 分子」では「表示 → 3D画面を画像で書き出す…」で、倍率（画面の画素数に対して1〜8倍）と背景（画面と同じ・白・透明）を選んでPNGに保存します。VTKでは画面の大きさのタイルに分けて描き、透明な背景は黒と白の背景で2回描いた差から求めます（半透明の等値面も透けます）。選択・候補・空いた配位サイト・末端の追加ハンドルなど編集用の印は描かず、ラベル・計測値・振動の矢印・等値面・軸の向きは画面のとおりに描きます。
- **構造列・振動の動画**: 「書き出し → 構造列を動画・連番画像で書き出す…」は、座標スキャン・IRC・NEBの点を経路の順（IRCは後退側の端 → 遷移状態 → 前進側の端）に、それ以外は構造列のすべてを書き出します。振動は「振動を動画・連番画像で書き出す…」で1周期の24枚です。形式は、MolFormaが書くGIFアニメーション（1枚ごとに最大255色、無限ループ）、MP4（H.264・yuv420p。PATHにある `ffmpeg` で作成し、ないときは選べません）、番号付きのPNG（フォルダー）から選び、倍率・背景・速さ（枚/秒）と往復（最後まで進んだら戻る）を指定します。GIFの透明な背景は1ビットの透明色で、輪郭は滑らかになりません。MP4は透明にできません。書き出しは中止できます。
- **グラフの図**: 結果ビューアのグラフ（IRスペクトル・吸収スペクトル・最適化の推移・経路）は右クリックの「図を保存（PNG・PDF・SVG）…」、「スペクトル」タブ・配座平均スペクトル・反応エネルギー図は「図…」で保存します。PNGは画面の2倍の画素、PDFとSVGは線と文字をベクターのまま保存します（画面の配色のまま）。SVGはQt SVGモジュールのあるビルドで選べます。

書き出しの倍率・背景・形式はアプリ設定に記憶します。画像の大きさは各辺16384画素までです。

## 結果の構造から再計算を準備

保存したジョブの結果を開き、使いたい構造を表示して「再計算を準備」を押します。元のジョブの保存内容を照合し、元の分子・計算条件・実行条件を未保存プロジェクトとして読み込んで、表示中の座標を編集候補にします。原子の対応と固定原子を検査し、候補を確定してから新しいジョブを実行します。通常のログ読込では最後の構造を初めに表示しますが、計算完了・最適化収束を保証するものではありません。Hessianやデータベースを引き継ぐNWChemの`restart`ではありません。

この操作は元の`input.nw`・`project.molforma.json`・`run.json`を照合できる保存済みジョブで使います。単独のログでは無効です。ログだけを使う場合は、対応する分子を開いて「分子へ候補として適用」、またはXYZへの書き出しを使います。

## ECD・ORD

「2 計算条件 → 励起状態」でTDDFTと「ECDの旋光強度」を有効にすると`cdspectrum`を生成します。長さゲージの励起エネルギーと旋光強度（10⁻⁴⁰ esu² cm²）を読み、正負を保ったLorentz曲線をeV軸に描きます。ピーク選択は「励起状態」の行と対応します。Δεへの換算、GIAO／速度ゲージのECDは未対応です。配座平均は「ツール → 配座セット…」の[配座平均スペクトル](molecule_pages.md#配座平均スペクトル)で、IR・通常ラマン・UV–Vis・NMRとともに行えます。

「物性 → ORD」で開始・終了波長と点数（2〜50）を指定すると、閉殻HF／DFTのGIAO応答を波長ごとに実行します。「スペクトル → ORD (β)」は光学回転βテンソルの等方成分（原子単位）を波長順に結びます。比旋光度への換算や線幅による畳込みは行いません。無減衰の実数値のみで、共鳴付近の線を定量的な補間と解釈しないでください。同じ波長が重複するログは別計算に分けます。入力の再取込は等間隔の波長列に対応します。

![過酸化水素のECD。正負を保った旋光強度のピークとLorentz曲線をeV軸で表示](images/results/06_ecd.png)

**図6** ECDの表示例。縦軸は計算した旋光強度で、Δεではありません。

## 物性3D・断面

![物性3D・断面で水の双極子の矢印と分極率の主軸・楕円体を表示](images/results/07_property_geometry.png)

**図7** 右側の専用ビューで双極子と分極率を表示します。倍率は表示用で、計算した値や原子座標は変更しません。

双極子または分極率を含むログは「物性3D・断面」で専用の分子表示を使えます。双極子の矢印は負から正への物理学の規約、単位はD、倍率はÅ/Dです。荷電分子の値は計算時の原点に依存し、表示位置を分子中心にしても値を再計算しません。読込時の座標と元ログを保持します。分極率は対称部分を対角化し、主軸とワイヤー楕円体を表示します。半径は正の主値の平方根に比例します。非対称・非正定値テンソルは拒否し、応答周波数も表示します。カメラ回転は分子と物性に同じ変換をかけ、座標を編集しません。

「2 計算条件 → 物性」の静電ポテンシャル／電場の大きさのCUBEを有効にすると、余白と各軸の点数を指定して`PROPERTY`の`ESP`／`EFIELD`＋`GRID`を出力します。ファイルは`開始名_esp_grid.cube`／`開始名_efield_grid.cube`です。ESP原子電荷とは別です。

電子密度CUBEを開き、「物性3D・断面 → 色付け用CUBEを開く…」でESP格子を指定すると表面を色付けします。原子順・元素・配置（10⁻⁴ Å以内）を検査し、表面全体を覆う格子を三線形補間します。位置合わせは自動で行いません。断面は色付け格子（未選択なら開いたCUBE）を用い、固定する格子軸と格子番号を選べます。断面の横縦は格子番号で、斜交格子を含む実空間距離の投影ではありません。

色尺度の下限（赤）・上限（青）を固定すると複数分子を同じ尺度で比べられ、断面と表面が同じカラーバーを共有します。CUBEの値の単位は生成条件で確認し、単位選択はラベルだけを変更します。ESPはEh/e、電場の大きさはEh/(e·a₀)のラベルを選べます。電場ベクトル・力線は生成しません。PNGに画面を書き出せます。格子は200万点まで、読込は中止可能です。

## MOLDEN軌道表示の検証

任意の実ファイルで、NWChemが出力したCUBEとの一致とGUI表示を検証できます（通常のCTestでは実行しません）。

```sh
QT_QPA_PLATFORM=offscreen MOLFORMA_MOLDEN_REAL=/path/to/benzene.molden \
  MOLFORMA_MOLDEN_CUBE=/path/to/benzene_homo.cube \
  MOLFORMA_MOLDEN_BASELINE=/path/to/baseline \

  MOLFORMA_MOLDEN_ARTIFACTS=/tmp/molforma-molden \
```

- `MOLFORMA_MOLDEN_REAL`: ベンゼン/6-31GのMOLDEN（66軌道、HOMOはAlpha 21番）。HOMO・LUMOを表示し、`MOLFORMA_MOLDEN_ARTIFACTS` に画面画像を保存します。
