# MCPサーバーの概要

`--mcp`（画面なし）と `--mcp-gui`（起動したGUIの文書を共有）でネイティブstdioサーバーを提供します。2026-10-24時点の最新安定版MCP **2026-07-28** のリクエスト単位の版指定・`server/discover` と、**2025-11-25** の初期化方式に対応します。

![`--mcp-gui` で起動したMolForma。MCPのopen_fileで開いたカフェインの窒素4個が選ばれ、ステータスバーに「MCP: open_file」「MCP stdio 接続中」が出ている](images/ai/01_mcp_gui.png)

**図1** `--mcp-gui` で起動し、MCPクライアントからカフェインを開いて窒素を選んだところ。ステータスバーの左に最後のMCPの操作、右に「MCP stdio 接続中」が出ます。

共通の26ツールで文書・部品取得、原子・結合・座標編集、溶媒和殻の配置、寸法（距離・角度・二面角）の設定、原子属性（元素・形式電荷・不対電子・同位体・質量・固定・ゴースト・原子名）の変更、測定、ファイル読込・保存、候補の確定・取消とUndo/Redo、NWChem基本・詳細・出力・実行条件の検査と変更、入力生成を公開します。文書IDと内容の版を指定して編集し、GUI側の変更との競合は拒否します。固定原子や未知のプロジェクトフィールドを保護し、変更を検証してから候補または履歴へ追加します。

`--mcp` は計算・結果用の4ツールを加えた計30ツールです。NWChemの実行・停止・入力一式の保存と、結果ファイル・計算フォルダーの読込・取消・取得ができます。計算はプロセス終了とともに停止します。

`--mcp-gui` は計43ツールです。SMILES生成・断片の追加・整形・配座探索・中止、NWChemの入力一式保存・実行・停止、履歴の走査・再利用・ごみ箱・CSV、結果の読込・取消・構造列・軌道・振動数・変位取得、虚振動を含むモードと構造列の再生・停止、PNG取得を公開します。その他の既存GUI操作も、部品一覧の取得、ボタン・メニュー実行、値入力、タブ・表・ツリー選択、セル編集、Qt内のマウス・キー入力で操作できます。確認・ファイル選択ダイアログをMCPで処理でき、OSの画面自動操作は不要です。

GUI変更は操作IDを返し、ダイアログ表示中も通信を受け付けます。背景の文書編集と破棄済み部品への操作を拒否します。GUIの確定・候補化・確認動作を引き継ぐため、操作完了と計算・読込の完了は別に確認してください。結果・カメラ操作は編集文書を変更しません。`results_action` の `apply_structure` だけは表示中の結果構造を文書の候補にし、`history` の `confirm` で確定します。

Claude Codeは `claude mcp add` または共有用の `.mcp.json` で登録でき、デスクトップの環境変数をそのまま引き継ぎます。2.1.310では新しい仕様で接続し、対話セッションではTasks拡張も使います。[Claude Codeの設定例](../mcp.md#claude-codeでの登録) を参照してください。

LinuxのCodexでGUI連携する場合は、`env_vars` に `DISPLAY` / `WAYLAND_DISPLAY` / `XDG_RUNTIME_DIR` / `XAUTHORITY` 等を設定し、デスクトップの接続情報を引き継ぎます。表示先が未指定の場合は、Qtの初期化前に標準エラーへ設定方法を出して終了します。[Codexの設定例](../mcp.md#codexでの登録) を参照してください。

MCPからはNWChemの実行ファイル・MPIランチャー・追加の環境変数・計算条件の追加入力を変更できず、MCPから開始する計算は利用者が設定した値でだけ実行します（`--mcp-allow-execution-settings` で解除）。`--mcp-allow-dir` を指定すると、MCPが読み書きする場所をそのディレクトリ以下に限ります。[安全のための制限](../mcp.md#安全のための制限) を参照してください。

計算の標準エラー（`molforma://calculation/stderr`）もリソースとして読めます。Prompts（作業手順4種）、`save_file` の上書き確認のElicitation、Tasks拡張（計算・整形・読込・履歴走査の完了までの追跡、`tasks/cancel` による中止、確認ダイアログへの回答）、文書・計算出力・結果のリソースに対応します。全ツールに `title` と `outputSchema` があります。stdioはLinux・macOS・Windowsで使えます。HTTP転送、購読、Sampling等は未対応です。受信1メッセージ・構造読込ファイル8 MiB、文書10,000原子、ヘッドレスUndo100回の制限があります。結果読込は既存ビューアの上限、GUI・結果一覧は約40 KiBのページで区切ります（1件のみの場合は2 MiBまで）。編集ツールは文書全体ではなく変更の要約を返します。標準入力を閉じるとGUIモードも終了するため、切断前に必要な文書を保存してください。更新後はMCPクライアントを再接続すると追加ツールが反映されます。[接続設定と詳細](../mcp.md) を参照してください。

## 1.1.0の計算・結果操作

計算用の`calculation`にキューの登録・開始／再開・一時停止・並べ替え・取消と失敗時の方針指定を追加しました。登録時の分子と条件を保存し、同時に1件ずつ動かします。`get_app_state`の`calculation.queue`で待機数と各項目の状態を確認します。GUI操作の完了やキューへの登録完了は、NWChem計算の完了とは別です。`enqueue` の `chainFrom`・`chainStructure`・`chainSteps` で、前の計算の最終構造・経路の最高点・IRCの端から続ける計算（遷移状態探索 → IRC → 両端の最適化の連鎖）を登録できます。NEBは `set_nwchem` の `task: "neb"` と、終点を設定する `set_neb_end` で準備し、`get_results` の `properties.neb` で経路を読みます。`--mcp-gui` の `chemistry` の `xtb` は、利用者が環境設定で指定したxtbで構造を最適化します。

`get_results`の`spectrum`・`spectrum_peaks`はNMR・通常ラマン・溶液ESR・ECD・ORD・IR・UV–Visの曲線とピーク、`energy_profile`は熱補正付きの段階別エネルギー（振動数スケール・準RRHO・1 mol/Lの補正、Gでは速度定数）を返します。単位・範囲・近似はGUIと共通です。配座セットなどのGUI操作は`ui_*`からも利用できます。接続し直した後にツール定義を取得してください。[キュー操作](../mcp.md#計算キューの操作)と[分光・エネルギー比較](../mcp.md#スペクトルエネルギー比較)に引数と返り値を記載しています。
