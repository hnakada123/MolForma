# MolForma

NWChem向けの分子作成・座標編集・計算入力作成を行う、Qt6 / C++20 のデスクトップアプリです。「1 分子」から「4 入力プレビュー」と「結果ビューア」「履歴」を実装しています。部品パレット、3D編集画面、座標表、NWChem入力の検査・出力を備えます。画面とマニュアルは日本語と英語に対応します（既定はシステムの言語。「環境設定」の「表示言語 / Language」で切り替え）。実行時にPythonは必要ありません。NWChemのローカル実行・停止・ログ表示、結果構造・振動・CUBE等値面の表示に対応します。保存した計算の履歴一覧、入力・ログの参照、分子と条件の再利用に対応します。

## ビルドと起動

必要な開発パッケージは Qt6 Widgets / Test、Eigen3、Open Babel 3、CMake 3.21以上、C++20コンパイラです。Ninjaを使う例:

```sh
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 4
ctest --test-dir build --output-on-failure
./build/molforma
```

構造ファイル（XYZ・MOL・SDF・Mol2・CML・PDB、NWChem・Gaussian入力、プロジェクト）を指定して起動できます。ウィンドウへのドラッグ＆ドロップや「ファイル → 最近使ったファイル」でも開けます。

```sh
./build/molforma tests/fixtures/ala_gly_ser.kgui.json
./build/molforma molecule.xyz
```

Qt Testが不要な配布用ビルドでは `-DBUILD_TESTING=OFF` を指定します。Open Babelの共有ライブラリに加え、フォーマットプラグインと力場データも必要です。Pythonバインディングは使用しません。RDKit C++開発パッケージをCMakeが検出すると、厳密な立体判定・記録と残基認識も有効になります。

Qt6対応のVTK 9.1以上の開発パッケージ（`GUISupportQt`、`RenderingOpenGL2`など）とQt6 OpenGL Widgetsがある場合、分子編集画面と結果ビューアの3D描画にVTKを使用します。VTKの外部依存の開発パッケージも必要です（配布によってMPI、FastFloat、nlohmann_jsonなど）。VTKはC++ APIで使用し、Python/PyVistaは不要です。配布時はVTKの共有ライブラリも含めてください。CMakeの `MolForma rendering:` 行で有効な構成を確認できます。

VTKがない場合や `-DMOLFORMA_ENABLE_VTK=OFF` を指定したビルドはQPainterで描画します。実行時に `MOLFORMA_RENDERER=painter ./build/molforma` で従来描画を選択できます。Qtのoffscreen/minimal環境とOpenGL 3.2コンテキストを作成できない環境では自動的にQPainterを使用します。詳しい動作と検証方法は [描画の説明](docs/features.md#3d描画) を参照してください。

```sh
cmake --install build --prefix /tmp/molforma-install
/tmp/molforma-install/bin/molforma
```

インストールすると、デスクトップのランチャー（`share/applications/molforma.desktop`）、アイコン、`*.kgui.json` と `*.nw` のMIME型も配置します。説明書は実行ファイルに組み込んでおり、「ヘルプ → 操作ガイド・マニュアル」（F1）で読めます。未保存の作業は1分ごとに自動保存し、異常終了した場合は次の起動時に復旧を確認します。

## 操作

MCPクライアントからも操作できます。GUIを表示する場合は `molforma --mcp-gui`、画面なしの場合は `molforma --mcp` をサーバーの起動コマンドに指定してください。最新の安定版MCP **2026-07-28** と **2025-11-25** をstdioでサポートします。Claude Codeでは `claude mcp add molforma -- /absolute/path/to/molforma --mcp-gui` で登録できます。MCPからはNWChemの実行ファイル・ランチャー・環境変数・計算条件の追加入力を変更できず、`--mcp-allow-dir` で読み書きする場所を限定できます。Claude Code・Codexの設定例、公開ツール、制限は [MCPサーバー](docs/mcp.md) を参照してください。

- 画面上部のヘッダーで作業の流れ（「1 分子」〜「4 入力プレビュー」・結果ビューア・履歴）を切り替え、右端の「計算を実行」（F5）で計算を始めます。「1 分子」は左端のツールの列・部品パレット・3D画面と座標の表・右側のページ（編集・変形・属性・配位・残基・電荷）で構成し、3D画面の上に今のツールの設定を表示します。3D画面の下の「3D」「3D＋表」「表」で座標の表の表示を切り替えます。
- 左のパレットで原子・骨格などを選び、中央をクリックして配置します。部品のドラッグ＆ドロップにも対応します。
- 原子をクリックすると選択し、Shift／Ctrl＋クリックで順に追加・解除します。2 / 3 / 4原子で距離 / 角度 / 二面角を測定し、「寸法を適用」で変更します。結合していない別々の分子の原子を選ぶと、後に選んだ原子の分子全体を動かします（二量体の距離・水素結合角など）。
- 左ドラッグで画面の縦・横軸まわりに回転（回転スライダーも追従）、右ドラッグで表示位置の移動、ホイールでカーソル位置を中心に拡大縮小。Shiftドラッグで範囲選択、Ctrlドラッグで選択を追加します。
- 配位子・配列構築・削除・整形などの候補は、3D画面の上のバナー（消える原子は赤、増える原子は緑、動く原子は橙で表示）の「変更を確定」またはCtrl+Enterで反映します。Escは候補の取消、Ctrl+Zは確定済み操作のUndoです。削除はどの方法でも同じ候補になり、その原子だけに付いていた水素も消します。キー操作の一覧は「ヘルプ → キーボードショートカット一覧」にあります。
- `.kgui.json` は結合・残基・配位中心・固定・同位体・点電荷・設定を保持します。旧形式の断片割当・拘束も保持しますが、作成・編集やNWChem入力への変換はしません。XYZは座標の交換用で、読込時に結合次数を推定します。既存のNWChem入力（`.nw`）は構造と計算条件を、Gaussian入力（`.gjf` / `.com`）は構造と電荷・多重度を取り込みます。
- 「表示」メニューで表示スタイル（ボール＆スティック・スティック・空間充填・ワイヤーフレーム）、原子の一時非表示、計測値の常時表示、水素結合の破線表示を切り替えます。「編集」メニューには点群の判定と対称化、Z-matrixの表示・編集、配座探索、構造の比較・重ね合わせ（RMSD）があります。
- 「ファイル → SMILESから作成」で水素付きの3D分子を生成します。構造だけを置き換え、計算条件・実行設定は保持します。「SMILESから断片を追加」「ファイルから断片を追加」では今の分子の横に別の分子を加えます。整形処理中は「整形を中止」で中断できます。
- 「1 分子」の座標の表で元素・X/Y/Z・同位体質量・ゴースト・固定を編集します。表のÅ/Bohr切替は表示だけを変えます。原子追加、削除候補、全体の原点移動、選択原子の一括固定・ゴースト、行の絞り込み、XYZの貼付・ドロップ読込・コピー・保存にも対応します。
- 表の「書き出し」メニューでNWChemの `geometry` / `constraints` ブロック（またはXYZ）をコピーまたは `.nw` / `.xyz` に保存できます。出力単位は表の表示単位と独立で、「2 計算条件」で設定します。形式電荷・不対電子・原子名も「属性の列」で表として編集できます。このファイルは座標部分の入力断片であり、計算には電荷・基底・手法・`task` を追加する必要があります。
- 「2 計算条件」でHF・DFT・MP2・CCSD系の手法、基底、全電荷・多重度、収束、最適化・振動数・遷移状態探索・IRC・座標スキャン、内部座標の拘束、COSMO・SMD、相対論（ZORA・DKH・X2C）、RI-J、物性（Mulliken・ESP/RESP電荷、NMR、分極率）、BSSE補正、最適化後の別条件での一点計算、検査しない追加入力等を設定します。電子数と組合せを検査し、座標・基底/ECP・計算条件・`task` を含むNWChem入力を生成します（コピー・保存は「4 入力プレビュー」）。左のセクション一覧に既定から変えた項目の数と今の計算で使わないセクションを示し、変更した条件は右の一覧から個別に既定値へ戻せます。組込み・ユーザープリセット、Undo/Redo、プロジェクト保存にも対応します。詳しい対応範囲は下記を参照してください。
- NWChem用の56項目の詳細設定（HF/DFTの収束、MP2/CCSD、最適化、振動数・熱化学、COSMO、軌道ファイル・保存先）は、「2 計算条件」の各セクションの「詳細設定」を開いて調整します。今の計算で使う項目だけを表示し、検索や「変更済み」の絞り込みにも含まれます。空欄は既定値を使用し、明示した値だけを基本条件へ上書きします。空欄の欄には実際に使われる値とその出どころを表示し、選んだ項目が入力のどのブロックに入るかを示します。項目・セクション単位のリセット、Undo/Redo、入力検査に対応します。
- CUBE・MOLDENの生成は「2 計算条件」の「軌道・出力ファイル」で有効にします。電子密度・スピン密度・HOMO/LUMOまたは番号指定の分子軌道、格子範囲・分割数、MOLDEN正規化を設定でき、入力プレビューと実行に反映します。

- 「3 実行設定」でNWChem実行ファイル、MPI起動数、OpenMP/BLASスレッド数、保存先、追加の環境変数を設定します。新規作成時の既定値は「編集 → 環境設定」で保存できます。メモリもここで設定します。計算はヘッダーの「計算を実行」（F5）で開始します。実行前の確認、ジョブとしての保存、非同期の実行・停止、時間制限、終了の通知と結果ビューアへの自動読込に対応します。実行中のtaskの段階と最適化の進み具合（ステップ・Gmax等の収束条件）、標準出力／標準エラーは、どのタブからでも開ける実行パネル（「計算 → 実行状況とログ」）に表示します。計算には別途NWChemと、MPI版では対応するMPIランチャーが必要です。
- 「4 入力プレビュー」で完成したNWChem入力を読み取り専用で確認します。行番号・色分け、検索、入力の構成（各部分を設定するタブ・詳細設定への移動）、詳細設定と追加入力から来た行の印、検証結果から設定タブへの移動、全文コピー・`.nw`保存に対応します。通常の書出し入力と、入力movecsのパスを解決した実行時入力を切り替えられます。プレビューと保存にNWChem本体は不要です。
- 「結果ビューア」でNWChemログ、XYZ構造列、CUBE、MOLDENを開けます。構造表示・エネルギー一覧（基準を選んだΔEと単位換算）、振動アニメーション・変位の矢印・連番画像とXYZへの書出し、IRスペクトル、スキャン・IRCの経路グラフ、原子ごとの電荷・NMR、原子の計測、CUBEの正負の等値面、MOLDENの分子軌道（HOMO/LUMO・一覧選択）の等値面を確認し、基準構造をXYZ・画面をPNGで書き出せます。実行パネルから直近のジョブを開くこともできます。結果の閲覧は編集中の分子を変更しません。「分子へ候補として適用」で、表示中の構造（最適化後など）を候補として「1 分子」へ取り込めます。「概要」は計算のエネルギー・最適化の収束・虚振動・HOMO–LUMOギャップなどをカードで示し、NWChemが正常終了していないログは警告を表示します。
- 「履歴」で保存済みの計算を日ごとの一覧で検索・状態別に絞り込み・並べ替えます。選んだジョブのエネルギー・記録・メモと操作は右側に、入力・ログは一覧の下に表示し、このウィンドウで実行中のジョブは実行パネルと同じ進み具合を示します。「ΔEを比べる」では、基準のジョブと組成・手法・基底・エネルギーの種類が同じジョブとの差を表示します。「分子・条件を再利用」は新しい未保存プロジェクトを作ります。表示中の一覧のCSV保存、実行中の計算の停止、終了したジョブのごみ箱への移動、プロセスが終了した「実行中」の記録の修復にも対応します。

機能の対応範囲、制限事項、検証例は [docs/features.md](docs/features.md) を参照してください。分子を組んで計算し結果を確かめるまでを題材ごとに通す実習（エタノール・金属錯体・ペプチド・BSSE補正・ラジカル・遷移状態など16題材、画面写真と練習データ付き）は [docs/recipes.md](docs/recipes.md)（英語は [docs/en/recipes.md](docs/en/recipes.md)）にあり、「ヘルプ → 操作ガイド・マニュアル」でも読めます。

## 開発

ソースは `src/`、Qt Testは `tests/`、説明は `docs/`、組み込みデータは `assets/` にあります。データはQt Resourceに埋め込み、実行時の作業ディレクトリに依存しません。

`src/` は責務ごとに分け、対応する `.cpp` と `.h` は同じディレクトリに置きます。

| ディレクトリ | 内容 |
| --- | --- |
| `src/model/` | 分子ドキュメント、保存形式、幾何計算 |
| `src/editing/` | 分子・座標編集、部品ライブラリ、ペプチド・配位構造、化学処理 |
| `src/nwchem/` | NWChem入力生成、詳細設定、可視化出力設定、実行制御、計算履歴 |
| `src/results/` | 計算結果の読込み、等値面生成、MOLDEN分子軌道の評価 |
| `src/ui/` | メインウィンドウ、各パネル、分子描画、UI部品、GUIを操作するMCPツール |
| `src/mcp/` | MCPサーバー（stdio・JSON-RPC）、共通ツール定義、画面なしの計算・結果読込、アクセス制限 |
| `packaging/` | デスクトップ連携（`.desktop`、アイコン、MIME型）。`docs/manual.qrc` で説明書とアイコンを実行ファイルに組み込み |

エントリーポイントは `src/main.cpp` です。ヘッダーは `#include "model/document.h"` のように `src/` からのパスで参照します。ビルドターゲットは `molforma_core`（model・editing・nwchem・results）、`molforma_mcp`（mcp）、`molforma_ui`（ui）に分かれています。

```sh
rg --files src tests -g '*.h' -g '*.cpp' -0 | xargs -0 clang-format -i
QT_QPA_PLATFORM=offscreen ./build/molforma \
  tests/fixtures/ala_gly_ser.kgui.json --screenshot /tmp/molforma.png
```

テストはネットワークや私有データを必要としません。アプリ設定とデータフォルダーは一時ディレクトリに切り替えて実行するため、利用者の設定を変更しません。画面設定とユーザープリセットは `QSettings("MolForma", "MolForma")` に、分子・計算条件・実行設定はプロジェクトに保存します。整形は同じ実行ファイルのワーカーモードを `QProcess` で起動し、一時ディレクトリのJSONで受け渡します。
